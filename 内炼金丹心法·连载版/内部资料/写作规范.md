# 第一部分 项目定案（最高决策，不得违背）

## 一、作品定位

- 《内炼金丹心法》（明·冲虚子伍守阳，公有领域古籍）的**小说化改编**，发布于**番茄小说**，传统文化/都市修行题材。
- **一部连续长篇**：第一单元为《内炼金丹心法》全本（卷一–卷十一+尾声），此后同一部书内按修炼次第连续化入其他道藏、佛藏修炼经典；人物与时间线贯穿不断，章节号全书累加，不开新书。新经典入场由剧情引擎带出（伍先生故交网络、陈默查书、伍先生阶段性换讲），次第由修炼逻辑定，不由写作方便定。
- 目标读者：完全没有古文、丹道基础的普通人。读小说=读经典=学会基本方法。

## 二、十项定案

1. **古文零出现**：正文里找不到成段古文。原文每句话的意思全部转化为故事性白话，藏进情节、对话、心理、动作。
2. **意思一句不落**：原文每句话（含"紫阳真人云"等祖师引文）都必须有对应的故事化表达。引文由"伍先生讲师门/祖师故事""陈默查资料"等方式消化。
3. **演绎三轨**：讲道理靠师徒对话；讲方法靠陈默亲身练习（怎么教、怎么做、错在哪、怎么改）；讲警戒靠支线事件。
4. **可照做**：教学场景写成可操作的步骤，读者跟着陈默就能练（仅限原书安全范围内的初阶内容）。
5. **第一人称**：叙述者"我"=陈默。支线场景用"我在场/事后转述/聊天记录"三种方式处理，不破人称。
6. **比喻配给**：每千字≤2个，全部出自人物职业生活（陈默=程序员、苏晚晴=病房、赵大鹏=生意）。细则见第十五条。
7. **短章**：每章2500–3000字（不得低于2500）。拉长靠加戏（电话、买卖、路人），不靠把句子抻长。
8. **拆章**：原书一章=一卷，拆成3–6个连载小章；原书顺序即修炼次第，卷序不得调换。
9. **五条支线全保留**（见人物表），支线为教学主线服务，不扩成言情商战。
10. **章末无板块**：不出现"下章预告/实修清单/安全提示"栏目。钩子化进故事最后两行；安全信息由"作品相关"卷声明+剧情台词承担。
11. **出处三段式（单书版）**：正文永远不含古文解析与出处说明（定案1不破），经典的出处与原文由三层外挂承担——
    - **简介层**：开放式点名。起点落真书名（"从明代伍守阳《内炼金丹心法》入门"级表述），后续经典虚指（"此后随师次第修习道藏佛藏多部真实经典"），简介不随连载进度改写。
    - **作品相关卷**：逐卷追加原文对照附录（本卷覆盖的原文段落+白话直译），与安全声明同卷；新经典开块时另起一节。连载越久附录越厚，长成"本书修习书目"。
    - **剧情层"书"物件线**：前期伍先生嘴上露书名不许看→中期陈默查书问难（"陈默查资料"自此为常规消化方式，不再是备用）→每部新经典一个出场事件→每单元收束于主角自读原文（第一单元的尾声即下一单元的入场门）。

## 三、覆盖工作法（保证"意思一句不落"）

- 写作前：从 `原著全文.txt` 取出本卷原文，逐段编号，拆分到各小章。
- 写作中：每段原文对应至少一个故事化载体（对话/体验/事件）。塞不进本章的段落挪到下一章，不硬塞——逐句覆盖守总量，不守单章。
- 交稿时：每章文件末尾加 HTML 注释标明覆盖范围，发布时删除注释。格式：
  `<!-- 覆盖原文：《XX论》第N–M段（"……"至"……"） -->`
- 每卷写完：回查编号表，确认无遗漏段落。

# 第二部分 正文创作规范（风格唯一真源）

## 九、核心原理（先懂为什么，再谈怎么写）

1. **检测器测三层可预测性**：
   - 语言层：句子质感（对仗、比喻密度、大词、节奏）——只洗这层，从"AI"降到"疑似"，到不了"人工"。
   - 素材层：内容通用性（换个人还成立吗）——疑似文的病根在这层。
   - 结构层：段落功能完备度（每段是否都为主题服务、闭环是否完整）——人工文的护城河。
   - 一句话本质：**AI 写"关于 X 的感受"，人写"事情的经过"。** AI 每个字都为主题服务，人有闲笔。
2. **人味 = 持续供应三种意外**：具体的意外（"碎过屏的红米"比"手机"难猜）、个人的意外（陈默的反应比"一般人"难猜，失眠的人听冰箱不听心跳）、无用的意外（洒豆浆的小孩比"有用的细节"难猜）。每章第一问不是"有没有AI句"，而是"这三种意外各够几处"。
3. **加法思维**：去AI味做减法，减到零也只是"不像AI"，执行过头还产生新的工整（v1 实测 82% 误报的教训）；人味做加法，目标"像人"，执行歪了也是人话的变种。
4. **检测器认知纠偏**：检测器对真人经典（《背影》原文）同样会标"疑似/AI"，任何仪器给不出 100% 人工。分数只看趋势，不当目标。目标是"像人说话 + 真好读"，收口永远靠出品人口述改写 ≥30%。
5. **诚实边界**：不写骗检测器的糙文（故意错字/病句/粗俗——伪装的人味有它自己的指纹）；禁网络热词、禁作者编造亲身经历冒充真实；人味只能来自真的人物、欲望、记忆、错误。0% 只是底线，根本目的 = 读者爱读。检测器和好读者要的是同一样东西：不可替代性。

## 十、写前（不做完不许动笔）

1. **定时间地点**：这章是几月几号几点几分、在哪、什么温度、光线什么样。说不出来 = 场景没想活，回去想。
2. **过电影**：闭眼把整场戏走一遍，随手记下 5–8 个**感官碎片**（声音/气味/触感/物件/吃的）。记碎片时不看原文、不想主题——碎片不许"有用"。这些碎片就是本章的人味弹药。
3. **先写裸对话**：把这场戏里人说的话先写出来，像剧本一样只有台词。对话搭起骨架，叙述后补。人说的话想不出来 = 这场戏还不存在，不能写。
4. **三问过闸**（每段动笔前问，答不上 = 这段不写）：
   - 这段里有没有一个字不为主题服务？（找不到 = 危险）
   - 情感最重的那三行里有没有比喻？（有 = 危险）
   - 这段换任何一个人还成立吗？（成立 = 通用素材，危险）
5. **取原文**：按第三节覆盖工作法取出本章要消化的原文段落，逐段编号。

## 十一、写中·生成纪律（六条）

1. **只写镜头里有的。** 想不出画面的句子，不写。形容词是想不出画面时的遮羞布。（摄像机原则）
2. **以说带写。** 每句叙述先在心里用陈默的嗓子念一遍，不像这人说的话，当场改。
3. **顺着时间流走，第一遍不回头装修。** 允许病句、重复、半截话。装修是朗读关的事。
4. **注意力不均匀。** 大事敢简笔，小事敢繁笔；越疼的地方越一笔带过（"苏晚晴走的那晚我倒睡得挺沉"）。**高潮压缩**：越大的事越短——两句话+一个画面收（赵大鹏出事、苏晚晴父亲去世均按此处理），禁止铺陈煽情。
5. **叙述者不比读者先懂，也不急着懂事。** 陈默永远"在场"，永远不"事后总结"。只报告，少解释，不铺垫（"我本来要去的，他不肯，只好让他去"）。他不知道自己在学丹道，他只知道自己睡不着、老头说话怪。
6. **原文的意思"长进"场景里。** 场景先生成，意思后藏入。

## 十二、写中·人声指纹（陈默的语言癖，全书固定，像他身份证上的痣）

1. **记账式数字**：房贷剩47期、甘油三酯2.8、煎饼八块五。对生活的失控感全部换算成数字。
2. **对吃认真**：食物永远有名有姓有温度。失眠的人别的欲望都淡了，就剩吃。
3. **失眠者的耳朵**：对声音异常敏感——冰箱、油锅、吊嗓子、野鸭子扎水。
4. **程序员自检**：「算了，想这些没用。」每章至多一次。
5. **对身体迟钝**：累了病了都用"还行"打发，直到打不住。

每章让其中 2–3 个癖好自然出场，像撒盐，不堆。

> 其他人物嗓音对照（写作时校准用）：伍先生=短句+口头禅+随手比喻（"漏气""先堵漏再加水"）；赵大鹏=江湖话+感叹号+哥俩逻辑；苏晚晴=医嘱式精确+反问。
> 伍先生口头禅（"先堵漏，再加水""气是饿出来的，不是憋出来的"级）**每卷复现**——既是番茄式记忆点，又承担教学复现功能，每次出场语境不同，不原样复读。

## 十三、写中·选词

1. **具体名词优先**：写物件必须带颜色/材质/品牌/数量中的一个以上。❌「他拿出手机看了看时间」✅「他划开那台碎过屏的红米，四点五十」。
2. **比喻三条铁律**：每千字≤2个；必须取自叙述者本人的生活经验（程序员用代码、医生用病房、厨子用灶），禁库存比喻；**情感最重的一段比喻数必须是 0**——顶点白描律：情感顶点全段只有动作和物件（爬月台买橘子全段零比喻，只有"攀、缩、倾"三个动词）。比喻密度与情感强度同向 = 指纹，反向 = 人工。
3. **副词形容词减肥**：一个名词前不许叠两个修饰语；"XX地"副词每段至多 1 个；写完删一遍，能删全删。
4. **成语大词配给**：一章至多 3 个成语，偶尔蹦出来一个，不按段均摊；禁止用文雅成语形容神态；口语判断代替成语（❌"物是人非" → ✅"店还在，人换了"）。
5. **意外但贴切的用词**：每章至少 3 处"不是最合理、但最像这个人会说的"表达（伍先生说"气跑了"，不说"气散于外"）。
6. **口语土词配额**："一股脑儿"级土词，每章要有。
7. **允许自我重复，词汇丰富度往下打**：同一个词连着用两三遍不换（"嗡嗡，嗡嗡，停一会儿，又嗡嗡"）。人说话就是重复。刻意同义替换式润色是 AI 本能（"忽然/突然/蓦地"轮着用直接枪毙）。
8. **平淡评估入场**："尚不大难""就不容易了""显出努力的样子"式笨拙判断，优于一切精准修辞。
9. **物件不象征**：衣服就报颜色（"黑布小帽、黑布大马褂、深青布棉袍"），不说它承载什么。

## 十四、写中·造句

1. **节奏三档量化**（统计口径：排除引号内对话的叙述句）：
   - 句长三档：短 ≤10 字 / 中 11–25 字 / 长 26–45 字；任一档占比 >55% = 警告；短句档参考 30–45%（对话密集章可上浮）；>45 字句全章 ≤3。
   - 连续 ≥3 个 ≤10 字短句 = 节拍器警告；连续 ≥5 个一句段 = 碎段海警告；相邻 ≥5 句字数差 ≤3 字 = 等长警告。
   - **短句无罪，短句成默认 = 指纹。** 短句只作重锤/转折/人声落地，不作默认节奏。全短句碎段海、等长句连排、全对仗长句，三个方向同罪。
   - 警告必须逐条处理或给出理由（对话密集章短句天然高，理由合法）。警告级不锁死——节奏是概率问题不是对错问题，硬锁会逼出"为达标而凑长句"的新模板。
2. **消灭对举结构**：「说长不长/说短不短」「不是……而是……」「一边……一边……」「足以……也足以……」「愈发……愈发……」「半是……半是……」出现即删。真人写时间感就一个字："两年了。"
3. **连接词限量**：「然而/因此/于是/与此同时」每章合计 ≤2 个。转场用句号，用场景切换，用人说话。
4. **允许半截话和口语**：对话里必须有语气词、口头禅、说半句咽回去（"我本要自己来，算了。"）。
5. **禁感悟四拍**：触发→情绪→回忆→感悟的节拍器结构；含"现在想来，那时真是太……"式忏悔收束。六类老病全章配额 0–1 条，连发 = 返工：感悟段（他想/他明白）/ 映射句（心界→现实对齐点破）/ 清单体（情绪报货单）/ 箴言古训（含"很久以前读过"包装）/ 内观报告 / 点破题眼句（"他听懂了"式——记忆点金句走金句配给，不许叙述者点破主题）。

## 十五、写中·叙事

1. **情绪只报事实，永不命名**：禁「涌起一股/说不出的/莫名的/复杂的 + 情绪词」。哭了就写哭了，不准形容哭。情感只允许三种出口——生理（鼻子一酸、手抖）、动作（筷子停在半空、把电视按了静音）、物件（盯着那只旧茶杯看了很久）。
2. **景物不表情（禁氛围先行）**：天气是天气，不是心情广告牌；场景不替人物先表态。只摆物件，情绪让读者自己长出来。
3. **动作按物理过程写，保留物流细节**：先做什么、后做什么，笨拙也写（"他先将橘子散放在地上，自己慢慢爬下，再抱起橘子走"）。无用步骤对主题零贡献，对真实满分。禁止用"艰难地""吃力地"一笔带过。
4. **素材层两条**：通用素材禁——闪回、反应、细节，换任何一个人还成立 = 删（这是疑似文的病根：语言洗白了，素材还是通用的；闪回必须写"只有他们家有过"的那件事）；动机要双标——切题动机之外带一个"别人"（"怕他看见，也怕别人看见"）。
5. **数字从生活来，不从修辞来**：「七百多个日夜」式诗性换算枪毙；「三年零两个月，房贷还剩四十七期」可以。活人数字挂生活，表演数字挂修辞。
6. **闲笔制度**：段段切题 = 摄像头叙事。每章 2–3 处"没用的细节"（茶凉了、楼下狗叫），至少 1 处彻底没用、没有下文的跑题（突然想起一件事，说完就完了）；**流水账合法**——起床洗脸刮胡子敢写成没用的流水账，真人记生活就是流水账，只有 AI 觉得每件事都得有意义。
7. **对话后不解释**：人物说完话，禁止作者跟一句"这句话的意思是……"。用沉默、动作、转场收。
8. **忏悔用自嘲，不用解释**：人物自我批评用反讽短句（"我那时真是聪明"），不用"现在想来，我那时太……"句式。
9. **对话占比 ≥40%**：每章至少安排一场"纯闲聊"戏（打电话、问价、寒暄），闲聊是人味主力产区；对话中必须含功能性废话（问价、找零、嗯、啊、"你说啥"）；叙述段里"自我对话"也算对话（自言自语、心里顶嘴），敢写。
10. **信息密度配给**：每章允许三成句子是低信息量的——重复、确认、绕回来重说一遍。句句有信息量 = AI。
11. **口吻向语音消息看齐**：叙述按"给朋友发语音讲这事"的松弛度写。语气词（吧、呢、啊、嘛）、口头禅（寻思、谁知道呢、能怎么办）、半截自我问答，全部保留不删。
12. **叙述者允许糊涂**：每章至多一处自我打断、改口、或"说不上来/记不清了"式的未完结思绪（限一次，用多了又成套路）。
13. **转场毛边**：每章至少一处跳切、倒叙或半途而废（用正常句式，如"算了"，不用破折号）。
14. **练功场景时间戳白描**：练习场景靠时间戳推进，不用一句感受词——"六点十分坐下，六分钟后左腿开始麻，第十八分钟打了个嗝"。读者自己得出"这人练进去了"，比"他感到气感"高级一百倍。
15. **教学场景干货密度**：教学给足物理颗粒度——坐具多高、脚怎么放、手放哪、数息数到几、错了是什么感觉。读者追着干货看，教学就不是负担而是卖点。颗粒度必须能在原文找到依据（§19.4 修炼内容零虚构）。

## 十六、写中·篇章

1. **段落长短不齐**：相邻两段不许一样长；一章里最长的段和最短的段至少差 3 倍。
2. **章末禁升华**：每章结尾用画面或钩子收，禁止感悟式总结（"那一刻，他明白了……"枪毙）。合法收法两种：**悬念收**（一个画面+未解之物）、**人物状态收**（落点是人物此刻的物理状态）。升的是状态可以，升的是道理不行。
3. **开头禁导语**：每章第一段写完，试删——如果删掉后更抓人，就删。
4. **节奏有松处**：一章里允许一小段"闲"（两个人不说话，各干各的），不许全程高能。
5. **金句配给制**：每章"精心打磨的句子"（漂亮比喻、警句、对仗收束）≤2 处，其余句子必须平庸。交稿前把全文第三好的句子删掉。
6. **反结构**：禁止列举式叙事（"第一条/第二条/第三条"），信息乱序、分次到场；章节标题不许与内容严丝合缝（禁用"三样东西"式概括型标题）。边界：**"做事"场景的物理清单合法**（采买、备料、步骤，"五金店：…杂货铺：…"式）；**"观点/感悟"的列举依然死罪**。
7. **破骨架节奏（2026-10-10 出品人拍板，读者体验层硬指标，与检测器无关）**：工作日默认动线"湖边→早点铺→公司→家"是招牌 routine（陪伴感底盘，不动），但连载追更下"换戏不换场"照样产生场景重复感——重复避让纪律管的是戏，本条管场。双轨执行：
   - **轻变奏（日常章随手用）**：不动场景，动时间槽/天气/人物配置——下雨天湖边没人、午休绕去湖边、下班顺路早市、老头今天不在（留悬念）、甩鞭子的没来等。零 canon 风险。
   - **定期注新（每 2–3 章一个破骨架章）**：兑现期待感台账里现成的场景钩（爸钓鱼水库/回妈家/初八进城观礼/王姨送罐），破骨架=既破重复又收期待感，一箭双雕。场景钩一律从欠债台账取，不为破骨架硬造新支线；周末章（周六/周日）天然优先排破骨架。
   - 连贯设计时本章属于"日常变奏章"还是"破骨架章"先定性，破骨架章动线必须绕开默认四点一线。

## 十七、标点（出品人五条禁令，最高优先，违者返工）

1. **禁止连续句号碎句**：不出现"五十九秒。我没听。"这类短句连发，短句并入逗号连接的正常长句。
2. **段首禁截句**：段落第一句不许戛然而止（段内第一个标点不能是句号），如"我也想睡。躺那儿……"必须合并。
3. **禁超短截句**：不写"得，我就听了。"这种只有一个逗号一个句号的叙述截句，句子成分写全，该并入前后句的并入（引号内对话不受此限，人说话天然短）。
4. **全文禁用破折号、省略号等特殊标点**：自我打断、声音中断改用正常句式表达（"算了，想这些没用"直接并入上下句，不加"——"）。
5. **对话规范**：对话一律加引号；对话尽量单独成段，但实事求是，不许所有对话都单独成段——紧贴动作的快节奏短对话（问价、找零、一应一答）可并进叙述。

保留条款（与五条禁令不冲突）：
- 分号全书基本不用（排比是 AI 味重灾区）。
- 感叹号配给制：基本只发给赵大鹏和真正受惊、真疼的时刻；陈默叙述全书 ≤5 个。
- 括号不进正文（那是写文档的习惯）。
- 冒号不给内心戏报幕（"他想："少用）；"他说："后必须跟引号对话。

## 十九、写后·交稿流程（顺序不可乱，不过不交稿）

1. **朗读关**：整章出声读。磕巴处、不像人话处，重写。
2. **抽句关**：随机抽 5 句，逐句审问：「这句换到任何一个失眠故事/修行故事里，能不能用？」——能用 → 删，或改成只有这章这人才会写的样子。
3. **排雷关**：全文搜索第十八节禁用词清单，命中为 0；过下面体检表。
4. **生活逻辑体检 8 项**（出品人训令：写的东西要严谨，要符合生活逻辑，实事求是。连基本常识都做不到，凭什么根据道藏原文教人修炼）：
   - 机制真实：文中涉及的 App 功能、制度、流程必须真实存在且工作方式正确（如：朋友圈点赞不显示点赞时间，动态发布时间可见；群消息无需"点开"，附件才需要）。
   - 因果成立：每个结果都有说得通的原因，不编造"恰好如此"的巧合。
   - 时间线一致：几点几分、几趟几次、"上个月/下周"，前后对得上。
   - 主语正确：谁做的事就是谁做的。
   - 常识核查：价格、剂量、医学名词、生活流程符合常识，拿不准的不写具体数。
   - 口语无歧义：方言口语、比喻若紧贴字面相冲，改用明白说法。
   - 人物一致：年龄、前史、人物表不冲突；新增细节不堵死后续剧情。
   - 修炼内容零虚构：凡涉及功法、功效的表述，必须能在原文找到依据，拿不准的宁可写"伍先生不让试"。
5. **交稿体检表**（逐项打勾，一项不过即返工）：
   - [ ] 禁用词清单命中为 0
   - [ ] 对举结构为 0；情感命名句为 0
   - [ ] 比喻 ≤ 每千字 2 个且全部来自人物职业/生活经验；情感顶点段比喻 = 0
   - [ ] 节奏三档无警告（任一档 ≤55%；无连续 ≥3 个 ≤10 字短句；无连续 ≥5 个一句段；无相邻 ≥5 句等长）
   - [ ] 成语 ≤3 个；连接词 ≤2 个
   - [ ] 没用细节 ≥2 处 + 彻底跑题 ≥1 处；意外用词 ≥3 处；口语土词有
   - [ ] 感悟/点破题眼类 ≤1 条；章末无感悟式总结；开头做过"删首段测试"
   - [ ] 对话占比 ≥40%，含一场纯闲聊
   - [ ] 标点五条禁令全过；另无分号排比、无括号补充、感叹号未超配
   - [ ] 生活逻辑体检 8 项全过，输出"已核无误/已修正"结论
   - [ ] 字数 2500–3000；末尾覆盖注释已加
   - [ ] 朗读测试通过
6. **出品人口述改写 ≥30%（最后且不可省略）**：AI 的人味是手艺，出品人的改写才是真人。推荐语音输入口述改写——口语天然带口误、语气词、半截话，是最强的人味注入，也是检测器无法被欺骗的最后一道防线和平台合规的根本保障。
